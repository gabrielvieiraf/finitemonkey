# Instructions for each task

Thank you for taking part. These are the same for all four tasks.

1. You get a task card with the goal, what "done" means, and any constraints. The project folder is already open.
2. Use Claude Code as you normally would. You can read the code, run commands, ask the assistant anything, and look things up on the web.
3. Please do not open the Finite Monkey repository during the study: it contains the checks we use to score the tasks.
4. When you believe the task is done, say "done" to the facilitator. If you want to stop without finishing, say "I give up". Both are fine. At 45 minutes the facilitator stops the task.
5. Some tasks have Finite Monkey on and some have it off. If it shows you a message, do what you would normally do with it, including ignoring it.
6. The facilitator can help with the setup (the terminal, the folder, Claude Code itself) but not with the task.
7. You will not be told whether a task passed our checks until all four are over, so that it does not change how you work on the next one.

After the last task, one question: compared to working without Finite Monkey, how much faster or slower do you think you were with it, in percent?
