# Instrucciones para cada tarea

Gracias por participar. Son las mismas para las cuatro tareas.

1. Recibe una tarjeta con el objetivo, qué significa "terminado" y las restricciones. La carpeta del proyecto ya está abierta.
2. Use Claude Code como lo haría normalmente. Puede leer el código, ejecutar comandos, preguntarle cualquier cosa al asistente y buscar en la web.
3. No abra el repositorio de Finite Monkey durante el estudio: contiene las comprobaciones que usamos para evaluar las tareas.
4. Cuando crea que la tarea está terminada, diga "terminé" al facilitador. Si quiere parar sin terminar, diga "me rindo". Las dos opciones están bien. A los 45 minutos el facilitador detiene la tarea.
5. En algunas tareas Finite Monkey está activado y en otras desactivado. Si le muestra un mensaje, haga lo que haría normalmente, incluso ignorarlo.
6. El facilitador puede ayudar con la preparación (la terminal, la carpeta, el propio Claude Code), pero no con la tarea.
7. No sabrá si una tarea pasó nuestras comprobaciones hasta terminar las cuatro, para que eso no cambie cómo trabaja en la siguiente.

Después de la última tarea, una pregunta: comparado con trabajar sin Finite Monkey, ¿cuánto más rápido o más lento cree que fue con él, en porcentaje?
