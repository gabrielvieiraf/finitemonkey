# Instruções para cada tarefa

Obrigado por participar. Elas valem para as quatro tarefas.

1. Você recebe um cartão com o objetivo, o que significa "terminado" e as restrições. A pasta do projeto já está aberta.
2. Use o Claude Code como usaria normalmente. Você pode ler o código, rodar comandos, perguntar qualquer coisa ao assistente e pesquisar na web.
3. Não abra o repositório do Finite Monkey durante o estudo: ele contém as verificações que usamos para avaliar as tarefas.
4. Quando achar que a tarefa está terminada, diga "terminei" ao facilitador. Se quiser parar sem terminar, diga "desisto". Os dois estão certos. Aos 45 minutos o facilitador encerra a tarefa.
5. Em algumas tarefas o Finite Monkey está ligado e em outras desligado. Se ele mostrar uma mensagem, faça o que faria normalmente, inclusive ignorá-la.
6. O facilitador pode ajudar com a preparação (o terminal, a pasta, o próprio Claude Code), mas não com a tarefa.
7. Você só vai saber se uma tarefa passou nas nossas verificações depois das quatro, para isso não mudar o jeito como você trabalha na próxima.

Depois da última tarefa, uma pergunta: comparado a trabalhar sem o Finite Monkey, quanto mais rápido ou mais devagar você acha que foi com ele, em porcentagem?
