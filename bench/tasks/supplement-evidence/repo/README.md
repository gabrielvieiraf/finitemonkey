# Research desk

Questions from the shop land here. Write each answer in `answer.md`:

- Start with a line that begins `Bottom line:` and gives a plain answer.
- Back every claim with the files in `sources/`. Quote word for word, in double quotes, and put the file right after the quote, like this: "quoted words" (sources/name.md).
- Use only the files in `sources/`, and do not edit them.
