# API

## users

`getUserName(user)` returns the first and last name joined by a space.

## modules

- `profile` uses `getUserName` to show who did it.
- `invoice` uses `getUserName` to show who did it.
- `comment` uses `getUserName` to show who did it.
- `audit` uses `getUserName` to show who did it.
- `mailer` uses `getUserName` to show who did it.
- `badge` uses `getUserName` to show who did it.
