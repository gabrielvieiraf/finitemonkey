# API

## users

`{{name}}(user)` returns the first and last name joined by a space.

## modules

- `profile` uses `{{name}}` to show who did it.
- `invoice` uses `{{name}}` to show who did it.
- `comment` uses `{{name}}` to show who did it.
- `audit` uses `{{name}}` to show who did it.
- `mailer` uses `{{name}}` to show who did it.
- `badge` uses `{{name}}` to show who did it.
